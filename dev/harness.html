Action Button — dev harness

A stand-in for a canvas app. Run npm run build first; reload after every build. This page is the only place the button can be looked at — npm run smoke asserts every decision it makes and has never seen it drawn.

What the host may not give you.

Off is a host that publishes no events bag at all. The platform types say that cannot happen, which is exactly why it is a switch: the control feature-detects, and with this off you can watch it fall back to its output properties.
